## Rules

- Figma defines layout, visual tokens, component states and responsive intent.
- Spring Boot owns authorization, pricing, inventory, order actions and all business state.
- Frontend consumes generated OpenAPI types; it does not copy DTOs or infer legal state transitions.
- Each mapped screen needs loading, empty, error and unauthorized behavior before its Plan 09 acceptance is marked complete.

## Priority order

1. Shared tokens and primitives: Inter, Emerald palette, navigation, buttons, inputs, feedback, overlay and data states.
2. Public buyer P0: `PUB-001…009`, then cart/checkout and order states.
3. Seller Center: navigation plus `SEL-001`, catalog, locations and incoming-order workflows.
4. Admin desktop: shell, dashboard, moderation and read-only operations.

For every row: retrieve the exact Figma frame `node-id` immediately before coding, implement mobile/desktop plus loading/empty/error/unauthorized states, then record visual-review evidence. Do not use this grouped table as a substitute for the frame-level comparison.
